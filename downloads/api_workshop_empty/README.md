# API Workshop Student Files

These are the fill-in-the-blank student versions of the four workshop sessions (the `-Blank` in each filename). The narrative and questions match the workshop website; the code chunks have strategic blanks (`________`) for you to complete during each session — city names, coordinates, endpoint paths, query parameter values, and column names.

Open the session file for the current class in Positron or RStudio. Keep the `images/` folder next to the QMD files so the visuals render correctly.

Completed answer-key versions of every session are on the workshop website.
